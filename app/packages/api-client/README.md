# @uhealth/api-client

Cliente tipado da API para os dois apps. `src/schema.d.ts` é **gerado** do OpenAPI do backend (`npm run gen:api` em `app/`; não edite à mão). Também: `criarApi`, `ErroApi`, `ProvedorUHealth`/`useSessao` (sessão e TanStack Query), `TelaLogin` e os rótulos pt-BR (`rotulos.ts`). Sem regra de negócio. Dono: F4.
